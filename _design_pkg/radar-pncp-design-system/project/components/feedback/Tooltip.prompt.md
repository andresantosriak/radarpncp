Hover/focus tooltip — explains score criteria, abbreviations, icon actions.

```jsx
<Tooltip content="Aderência técnica + CNAE + prazo + valor + risco">
  <IconButton label="Como o score é calculado"><i data-lucide="help-circle"></i></IconButton>
</Tooltip>
```

`placement`: top (default) / bottom. Wraps any trigger element.
