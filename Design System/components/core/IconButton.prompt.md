Square icon-only button for toolbars, row actions and the topbar. `label` is required (a11y + tooltip).

```jsx
<IconButton label="Filtrar" variant="outline"><i data-lucide="sliders-horizontal"></i></IconButton>
<IconButton label="Favoritar" active><i data-lucide="star"></i></IconButton>
<IconButton label="Buscar" variant="solid"><i data-lucide="search"></i></IconButton>
```

Variants: `ghost` (default) · `outline` · `solid`. Sizes `sm`/`md`/`lg`. `active` toggles brand-soft.
