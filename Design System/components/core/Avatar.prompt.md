User or órgão avatar — initials by default, image when provided.

```jsx
<Avatar name="Marina Alves" />
<Avatar name="Prefeitura de Sobral" shape="square" tone="neutral" size="lg" />
<Avatar src="/u/123.jpg" name="João" size="sm" />
```

`size`: sm/md/lg/xl or a number. `shape`: circle (people) / square (órgãos). `tone`: brand/gold/neutral.
