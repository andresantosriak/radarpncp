Keyword / filter chip — saved search terms, active filters, required-document tags.

```jsx
<Tag selected onClick={()=>{}}>inteligência artificial</Tag>
<Tag onRemove={()=>{}}>chatbot</Tag>
<Tag icon={<i data-lucide="file-text"></i>}>Termo de referência</Tag>
```

`selected` highlights; `onClick` makes it a toggle; `onRemove` adds a × button.
